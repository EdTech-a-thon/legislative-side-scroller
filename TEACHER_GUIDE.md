# Capitol Hill Crawler: Teacher Guide

## Purpose

Capitol Hill Crawler is a civics study game for students learning how a bill becomes a law and preparing with the 2025 USCIS 128-question civics bank. Students play as a freshman U.S. Representative attempting to pass the fictional **Connected Classrooms Act** through the House, Senate, and White House.

The game is designed to support instruction, review, and an optional completion-based assessment.

## What Students Learn

- U.S. civics vocabulary and citizenship-test content
- House and Senate roles in the legislative process
- Committees, amendments, debate, filibusters, cloture, vetoes, and overrides
- Coalition-building and communication approaches
- How practical details affect support for a bill
- How to use study resources, feedback, and retry opportunities

## Recommended Classroom Use

### Before Students Play

1. Share `STUDENT_INSTRUCTIONS.md`.
2. Explain that the game uses a simplified classroom model of government procedures.
3. Remind students that completion is the assessment goal; the score is optional competition.
4. Confirm that each student is signed into their own Chromebook/browser account.
5. Ask students to create an appropriate Representative name that they can recognize later.

### During Play

- Encourage students to use the Notebook and Vocabulary Guide between encounters.
- Let students work individually, in pairs, or with limited peer discussion depending on your assessment goal.
- Circulate for question wording, map navigation, and civics-vocabulary support.
- Encourage students to read the feedback after missed questions. A missed question becomes useful study material even if it does not repeat in that campaign.

### Suggested Time Structure

- Day 1: Rotunda, House tutorial, early House exploration, Notebook study.
- Day 2: House passage and Committee Dungeon.
- Day 3: Senate, Holds, Filibuster, and Overtime.
- Day 4: White House, final review, and completion record.

Students may also complete the game over a longer unit or use it as an independent review activity.

## Assessment and Grading

### Recommended Grade Evidence

Use the **Completion Record** as the primary submission artifact.

After a student completes the game:

1. They choose **Lock In Score**.
2. They click **Download Completion Record**.
3. They attach the downloaded PNG to a Google Classroom assignment.

The record includes:

- Representative name
- Completion result
  - Bill Signed Into Law
  - Veto Override Completed
- House support total
- Senate support total
- Notebook entries collected
- Remaining Influence
- Final score

### Grading Recommendation

Grade completion rather than rank or score.

Example rubric:

| Evidence | Suggested value |
| --- | ---: |
| Completion Record submitted | 50% |
| Bill became law | 30% |
| Student reflection, exit ticket, or vocabulary check | 20% |

Score can be used for discussion, personal goals, or friendly comparison. It should not be the main grade because students may make different strategic choices about Shop purchases, exploration, and Notebook collection.

### Lost Completion Record

The game saves the most recent locked completion record separately from the active campaign.

If a student accidentally starts a new campaign before downloading their PNG:

1. Return to the title screen.
2. Choose **View Last Completion Record**.
3. Download the record again.

The newest locked completion record replaces the previous one.

## Current-Officeholder Questions

Some USCIS questions depend on a student's jurisdiction or current elected officials.

### Student Profile

Students select a state or territory and may optionally enter a city. This supports state-capital and other location-based questions.

### Answer Rules

- Last name is usually enough for an official.
- A first name is needed only if two relevant officials share the same last name.
- Full names are always accepted when correct.
- Students are never penalized for unavailable, stale, or ambiguous district/current-officeholder data. The game swaps the question instead.

### Data Review Schedule

Current-officeholder data is scheduled to refresh on:

- January 28
- August 28

The game uses official public sources for Senate and Governor data. The student profile notes the dataset's last verified date.

### U.S. Representative Question

A U.S. Representative is determined by congressional district, not state alone.

When Question 29 appears, students may:

- Allow one-time location use
- Enter a ZIP code
- Skip the question without penalty

Precise location and ZIP information are not stored in the campaign, Notebook, completion record, or teacher-facing data. Until a hosted district lookup is connected, this question safely swaps out.

## Save and Device Notes

- Each Chromebook/browser profile has its own local save.
- Students sharing the same browser profile share a save, so individual sign-in is important.
- Clearing browser site data can erase local progress.
- The game currently uses one active campaign save per browser profile.
- Students can save manually at the Rotunda Save Station; major milestones also save automatically.

## Playtest Checklist

Before assigning the game to a class, test this short path:

1. Start a new campaign.
2. Create a Representative and select a jurisdiction.
3. Enter the House and complete Mr. Ben Venello's tutorial.
4. Test one multiple-choice and one open-ended answer.
5. Open the Notebook and Vocabulary Guide.
6. Buy a Notebook entry or power-up in the Shop.
7. Verify movement, NPC interaction, and save behavior.
8. Confirm the Completion Record can download in the target browser.

## Troubleshooting

| Issue | Suggested response |
| --- | --- |
| Student cannot move | Click the game area, then use arrow keys or WASD. Check whether a dialogue or Notebook window is open. |
| Student cannot type an answer | Click inside the answer field. Movement keys do not activate while an input field has focus. |
| A current-official answer does not work | Check the Last Verified date. If data is unavailable, allow the question to swap rather than marking the student wrong. |
| Student used the wrong name | Start a new campaign before significant progress, or use the existing name if it is still identifiable for the completion record. |
| Completion record was not downloaded | Return to the title screen and choose **View Last Completion Record**. |
| Student is stuck on a map | Have them use the Rotunda return route or restart the browser session. Report the map location for a future fix. |
